# contact

Contact page served by GitHub Pages at <https://tehbaer.github.io/contact/>.
Printed QR labels (see `~/kode/etiketter`) point at that URL, so it must never
move. The repo name and the Pages setting are what keep it stable.

To update: edit `index.html` and `contact.vcf` (keep them in agreement, and bump
the "Oppdatert" date), commit and push. Pages redeploys within a minute.

Pages setup: Settings → Pages → Deploy from a branch → `master` / `(root)`.
